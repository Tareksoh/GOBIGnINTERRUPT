# Changelog

## v0.1.0-beta — 2026-04-27

Initial public beta.

- M+ party CD tracker with two configurable bar windows (Interrupts, Cooldowns)
- Interrupt-pull alert with configurable delay and sound
- Burst-ready alert when all tracked big CDs are simultaneously up
- Per-dungeon kick counter (resets on CHALLENGE_MODE_START)
- Party-frame overlay mode (OmniCD-style)
- Cooldown DB cross-referenced with OmniReborn + MiniCC for 12.0.5 accuracy
- Sounds, minimap button, scrollable Settings panel
